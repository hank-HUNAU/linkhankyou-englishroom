# 教师备课本（teacher-vocab-prep）

本技能是 **article-vocab-analyzer 主技能的软分支/后处理**：不重复分词与分层，而是复用主技能产出的"唯一 lemma + 归属层 + CEFR + 词性 + 频次 + 跨句 Range + 原文原句 + 超纲"，加工成**教师备课**可直接用的结构化素材。

## 定位

- **纯静态、零联网**：只调主技能 `assess_vocab.py`，不在线补词典、不强依赖 nltk，跑得快、稳，适合备课；教师词卡如需释义/音标，可另跑学生分支 `student-vocab-cards`。
- **教学梯度映射**：KET/PET → **全员(基础)**；NGSL → **中阶**；NAWL/out → **中强(超纲/进阶)**，贴合分层教学（全员/中/中强）。
- **命题视角**：把"学生版刻意隐藏的教师备课信息"显式化——逐实词给**考点类型提示**、**可挖空填空句**、**考情难度提示**。

## 输出（Excel，多页签，贴合分页签工作习惯）

| 页签 | 内容 | 备课用途 |
|---|---|---|
| 分层词卡 | 教学梯度/归属层/词/词性/频次/跨句Range/CEFR/原文照搬/类型 | 分层重点讲读、听写目标词筛选（按频次优先）|
| 考点命题矩阵 | 逐实词(n/v/adj/adv)：原文照搬 + **可挖空填空句** + **命题参考**(时态/单复数/搭配…) + 考情提示 | 直接取材出挖空/听写/选词题 |
| 超纲进阶补卡 | out/NAWL/NGSL 词按频次降序 | 进阶讲读、跨篇补卡 |
| 单元考点统计 | 各层词条数与占比、高频词 TOP15 | 单元难度概览、重难点分布 |

## 用法

```bash
python scripts/teacher_prep.py --file 课文.txt --out 教师备课本
python scripts/teacher_prep.py --text "..." --out 备课
python scripts/teacher_prep.py --file 课文.txt --band "全员(基础)"   # 只挑某教学梯度(逗号分隔)
python scripts/teacher_prep.py --file 课文.txt --out 备课_A          # 按课次分开出件
```

> 输出与入口：结果写 `<out>.xlsx`（四个页签）；复用主技能所见即所得，无需联网等待。
> **推荐**：经主技能一键管道调用——`python scripts/vocab_pipeline.py 课文.txt`（默认含备课本；`--steps 主,备课` 只出这步）。

## 边界（重要）

1. **命题参考是自动化建议**：考点类型、挖空位、考情提示皆由词性/分层/CEFR**启发式生成**，属备课起点，须结合教材与班情人工复核（尤其"考情提示"中的 CET 提示仅为难度定性，非真题命中）。
2. **版权红线**：KET/PET/中高考真题仅可参考词表自创**同构仿真题**，不得照搬真题原文作为命题稿。
3. **覆盖口径**：统计页为"词条口径"（去重 lemma 计数），非 token 口径；完整覆盖率看主技能报告。
4. **同形异义词（homograph）**：found/left/rose 等自动命题需人工确认语境义。
5. **超纲词有原句、无词性**：主技能「超纲词」表现带**原文例句**（补卡可见）；词性因超纲词无词表词性、本分支离线不联网，故"分层词卡/矩阵"中词性为空属正常。
6. **不预置版式**：本分支不预设任何教案版式/界面，只交付结构化备课数据；具体成稿由你二度加工。
