# 译文产出规约 v1.1

> **地位：四六级汉译英处理链条的「第二规约」，受《原文处理规约》指导。** 译文是解空间，允许多解；本规约规定：据原文处理已产出的决策，按固定字段顺序产出译文与学理标注，遵守来源分级纪律，并允许"追加候选、不删旧译"。
>
> 生效：自 **2026.12 批次**起录入统一执行；2026.06 六套样板书按本规约回溯补标 `原文处理` 行并**回校**，不重译。
> 本规约由原散见于 `SKILL.md` 的产出规则**收敛独立**而来；`SKILL.md` 自此改编排器，细则以三份规约文档为准。

---

## 1. 定位与产出顺序

- **输入**：`原文处理规约` 的六类处理结论 + 汉语原句。
- **一句内字段顺序（固定）**：
  `原文（句题）→ 原文处理 → 译文 → 来源 → 策略 L1 → 技巧 L3 → 语块 L2`
- 学理标签（CL/SB）为伴随核验信息，不单独计数为一级字段；7 标签本体（原文/译文/来源/策略L1/语块L2/技巧L3/学理）不变，`原文处理` 为**句内首位决策行**，不新增第 8 一级标签。**L1/L2/L3 表示标注层级，不构成行序约束**：行序上文所列即唯一实际行序（策略 L1 → 技巧 L3 → 语块 L2），与六套合并样板（33 句）完全一致。

## 2. 译文质量判据（对外表述口径）

- 以 **功能主义为主干**（译文忠实、通顺、简洁，按交际目的与受众调整），以 **Nida 1964 功能对等**的自然可读作判据；若需学术定位，表述为"**功能主干 + 构式翻译单位 + 语料验证**"（学理背景见真题侧论文目录文献 `_cet采集\汉译英研究现状梳理_策略与技巧.md` 第七章——**非技能运行依赖**，技能目录不打包该文，仅作学术口径来源）。
- **忠实**：不得增删原文事实；文化负载词按 `来源分级` 处理。
- **通顺**：符合英文语序/形合/时态习惯（英汉对比依据见学理标注规则）。
- **简洁**：不逐字硬译，可合并分句、收敛冗余（如"增收致富"→increase incomes）。

## 3. 来源分级纪律（S1~S4）

| 级别 | 含义 | 处理 |
|---|---|---|
| S1 | **官方短语**（China Daily / 新华 / gov / 使领馆英文版等可定位 URL） | 给出出处 URL，仅用于句中对应短语，不冒充整句出处 |
| S2 | **编译整句**（无逐句官方译文，自行整理） | 标注"整句无官方译文（整理编译）" |
| S3 | **非官方参考**（第三方/教育机构/标准库等） | 明确标"非官方参考"，供对照不作判分依据 |
| S4 | **未确证 · 按语境通译** | 明示无权威英文源，按其义通译，不得伪装有出处 |

**判定铁律**：渠道限定（只认官方媒体/政府网域）；检索可定位（URL 能打开、能对应到该短语）；凡存疑一律降级到 S4 并注明。官方从不公布标准译文，凡无可靠英文出处的句子一律如实标"无官方译文（整理编译）"，**绝不伪造或臆造 URL**。

## 4. 多解原则与追加候选流程

1. **允许多解**：同一汉语触发点可产出多个合法英文结构；`原文处理` 行的候选集即是译文候选的依据。
2. **追加不删旧**：某句若回溯/回校时发现更优构式，**追加**为新候选译文并标注（追加日期 + 对应原文处理标签），**不删除**原译文。
3. **回查**：每条译文在其句内可回查到 `原文处理` 决策行（双向可追溯）。
4. **旧译文处置**：不因决策顺序调整而重译；旧译文如与原文处理候选集一致即视为有效，如不一致则进入追加候选流程。

## 5. 学理标注规则（L1 / L2 / L3）

- **策略 L1 宏观**（英汉对比层）：补主语/话题转主语、意合→形合、语序重排、名词化、使役转移、被动选择、后置定语。
- **语块 L2**：词块（L2·PC）与句法框架（L2·SB）登记细则见 `学理自查规约.md` 第 7 节；高频框架见 `L2·SB_高频句法框架清单.md`。
- **技巧 L3 微观**：Molina & Albir 2002 / Vinay & Darbelnet 1958——词性转换、增补(Amplification)、省略(Reduction)、惯用等值。
- 学理依据**标准出处**（避免错挂）：
  - 话题/主语凸显：Li & Thompson 1976
  - 意合→形合、语序重排、修饰语位序、时态呼应：连淑能 1993《英汉对比研究》
  - 翻译评价尺度（自然可读判据）：Nida 1964 功能对等
  - 惯用等值/词性转换/句法转换：Vinay & Darbelnet 1958、Molina & Hurtado Albir 2002
  - 语块/词汇法：**Lewis 1993**（非 Nation）
  - 构式依据：认知构式翻译观（见研究现状第七章）
- 典型错误挂法（避免）："形合-意合"归 Nida（应归连淑能）；"语块法"归 Nation（应归 Lewis）。
- **触发词—译文特征对齐（录入硬约束）**：L1/L3 中写入学理触发词（分词/目的/被动/使役/名词化/形合/时态/增补/动名词主语/定语从句）之前，**须先在译文中定位对应特征**；定位不到则不写该触发词。六类高频误触发（**分词、目的、增补、动名词主语、形合、时态**）的"覆盖—不覆盖—推荐写法"对照表见 `学理自查规约.md` **§5·附 录入须知**，**录入前必查**。

## 6. 抽检回校链路

- 译文 + L1/L3 产出后，由 `学理自查规约.md`（第三规约）做**译文侧一致性抽检**（CL-01~11 断言）。
- 抽检不解析 `原文处理` 行；原文处理行的质量由"处理先行 + 回校"人工把关。
- 报告头带规约版本 + 运行日期，保证复评与当年规约对齐。

## 7. 免责

- 技能输出定位为**教学资料**（学生预习/讲义/课堂讲练），**非考场自测学习材料**：四六级官方从不公布标准译文，本输出译文来源标注依检索当下可得而分级，**不代表官方定稿**，不得作为判分依据。
- 谚语/俗语无官方标准译法时，一律按 S4 通译并在来源中明示，不硬套出处。
