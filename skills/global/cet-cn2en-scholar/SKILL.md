# 四六级汉译英 · 原文先行 · 三规约闭环

> 处理链条：**汉语原文是最重要的译文依据**。逐句先做「原文处理」（第一规约），据其决策产出「译文 + 来源 + L1/L2/L3」（第二规约），最后做译文侧一致性抽检（第三规约）。
> 本技能为**编排器**：只沉淀可复用方法论与流程、不携带真题数据；细则以三份规约文档为准，高频句法与固定短语见随行参考库。

## 触发条件（when to invoke）

当用户提供四六级（或同类）**汉译英真题原句**，并希望产出以下任一结果时调用：
- 逐句**译文 + 来源分级标注**（要求可证来源、不得编造）
- 带**翻译策略(L1) / 翻译技巧(L3)** 学理标注的学习卡 / 讲义
- 对已有标注做**学理—译文一致性抽检**
- 对汉语原文做**六类功能处理**（断句/话题/触发/时锚/逻辑/文化）

## 输入约定

- 输入：一段或多段汉译英中文原文（可按题分段的整卷，或单句列表）。
- 若原文缺整句完整、恐有二手整理出入，须按句如实标注"仅作教学参考用"。
- 官方从不公布标准译文：凡无可靠英文出处的句子，一律如实标"无官方译文（整理编译）"，**绝不伪造或臆造 URL**。

## 工作流程（三规约编排，逐句执行）

```
① 原文处理规约（第一 · 输入侧）     读汉语句 → 六类功能处理 → 产出 原文处理 决策行（候选集，多解）
        ↓ 指导
② 译文产出规约（第二 · 产出侧）     按句内字段顺序产出 译文/来源/策略L1/技巧L3/语块L2
        ↓ 事后核验
③ 学理自查规约（第三 · 抽检侧）     CL-01~11 断言核验译文侧一致性；不解析原文处理行
```

- **句内字段顺序（固定）**：`原文（句题）→ 原文处理 → 译文 → 来源 → 策略 L1 → 技巧 L3 → 语块 L2`。**L1/L2/L3 为标注层级，非行序约束**；本行序与六套合并样板（33 句）一致。
- `原文处理` 为句内首位决策行；7 标签本体不变，**不新增第 8 一级标签**。
- 旧语料处置：不因顺序调整而重译；2026.06 六套样板回溯补标 `原文处理` 行（追加候选、不删旧译）。

### 关键规则速览（细则见对应规约）

- **来源分级 S1~S4**：S1 官方短语（China Daily/新华/gov/使领馆等可定位 URL）；S2 编译整句；S3 非官方参考；S4 未确证·按语境通译。铁律：渠道限定、检索可定位、存疑一律降 S4、绝不臆造 URL。
- **学理标注规则**：L1 宏观（英汉对比层）；L2 语块（L2·PC 词块 / L2·SB 句法框架）；L3 微观（Molina & Albir / Vinay & Darbelnet）。学理出处避免错挂：意合形合→连淑能；话题主语→Li & Thompson；语块→Lewis；评价尺度→Nida。
- **触发词—译文特征对齐（录入硬约束）**：L1/L3 写入学理触发词前，**先在译文中定位对应特征**；定位不到就不写该触发词。六类高频误触发（分词/目的/增补/动名词主语/形合/时态）的"覆盖—不覆盖—推荐写法"对照表见 `学理自查规约.md` **§5·附 录入须知**（v1.4），**录入前必查**。
- **原文处理六类**：断句·核心句 / 话题→主语 / 触发→SB 候选 / 时锚 / 意合逻辑显式化 / 文化负载词分级。不做完整句法树；无点省略；多候选、不称唯一。
- **L2·SB 登记**：只登记高频可迁移骨架，写法=骨架+槽位+本句实例；禁止全句通配误标。

## 输出形式

- **学习卡**（推荐）：展示 原文 / 原文处理 / 参考译文(关键短语高亮+来源脚注) / 翻译策略 / 翻译技巧 / 重点表达 / 复现表达。
- **双语讲义**：A4 排版逐句清单（按句内字段顺序）。

## 结构化示例（通用化，非真题）

```markdown
### 句 N
**原文**：…（汉语原句）
**原文处理**：断句:核心=②；①→时间状语(As…,主句)；触发[使]→enable+A+to do B|allow+A+to do B|make+A+able to do B；时锚:近年来→现在完成|现在一般
**译文**：…
**来源**：S4 · 整句无官方译文（整理编译）；"XX"对应官方短语见 [ChinaDaily](https://…)
**策略 L1**：补主语 / 意合→形合（连淑能1993）
**技巧 L3**：词性转换 worldwide；增补 glass（Molina&Albir2002）
**语块 L2**：maintain a long reputation（L2·PC）；`S + not only + V + but also + V`（L2·SB） → 本句实例：… not only … but also …
```

## 边界与免责

- 技能输出定位为**教学资料**（学生预习/讲义/课堂讲练），**非考场自测学习材料**；译文来源标注依检索当下可得而分级，不代表官方定稿。
- 谚语/俗语（如"一日为师终身为父"）无官方标准译法时，一律按 S4 通译并在来源中明示，不硬套出处。
- 原文处理为教学级功能标注（非完整词法句法分析），译文允许多解；任何标注不声称唯一译法。
