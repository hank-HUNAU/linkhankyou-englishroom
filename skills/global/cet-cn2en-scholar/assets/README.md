## 二、登记口径（与三规约一致）

- 来源分级 **S1**（官方短语，可定位 URL）/ **S2**（编译整句）/ **S3**（非官方参考）/ **S4**（未确证·按通译）。
- **S1 多源交叉核验**：核心短语标 S1 前并行检索 China Daily / Xinhua / CGTN / SCIO 等官方英文源，跨源一致方高置信保留 S1 并逐源附 URL；仅单源命中降为 S3（机构注记）。
- **只登记能定位、可复用的短语**；拿不准的英文或不能打开定位的出处一律降级，**不冒充、不臆造 URL**。
- URL 均为采录时检索所得；若失效或无法对应，应按铁律**降级并重查**，不硬留。
- 未收录"无官方译文"的整句（那属于 S2）。

## 三、L2 类标注列（`official_phrases.md` 专属）

该表的"分级"列**混装两类信息**，读取时须区分：

- **S1/S2/S3/S4** → 该行的**来源分级**（同 §二）。
- **P / IE / PC / SB** → 该行的 **L2 语块类名**（Nattinger & DeCarrico 1992 四分类：`P` 多元词 / `IE` 习语式 / `PC` 短语构式 / `SB` 句型框架）。

> 该表 **T 节「L2 类」列现有 136 行**类标注（**PC 84 / P 28 / SB 22 / IE 2**；其中词块表 127 行 + SB 模板表 9 行；经脚本实测），是 **L2·PC 词块补登**（收官后续事项）所用**类词典**。补登的**登记口径**（汉语识别 → 英文准入 → 汉英落笔）见 `../学理自查规约.md` **§7**。
>
> ⚠️ **覆盖率提示（§7 第 4 条）**：本表英文列**未列全候选**时会产生"假阴性"（该句译文其实命中，却因词典缺该变体而漏登）。因此补登以**主库的全候选英文**做匹配、以**本表的 L2 类**做归类，二者结合方为完整词典。
>
> 📌 **本表 T 节是唯一"可继续扩写"的一节**：A–S 节为历史官方短语登记（不再扩写，避免重建双源），而 **T 节即 L2 类词典**——新词块须**先补 T 节**（出类名）、同条补**主库**（出候选），方能被 `_backfill_l2.py` 准入。已例：2026-09-21 为升级 `CET4 2025.12 S3` 句2 遗留行，补入 `一系列措施`／`显著改善` 两条（T 节 + 主库同步）。

## 四、更新节奏

- 每跑一套新真题：命中的新官方短语登记进 **主库** `../固定短语参考库_累积.md`；**A–S 节不再扩写**（避免重建双源）。**例外——T 节（L2 类词典）须持续扩写**：新增可复用词块时，**T 节补条目（出类名）+ 主库同条补候选（出一汉多译）**，两侧同步，否则 `_backfill_l2.py` 无法准入该词块。可归纳的新题型手法归并进 `type_to_tactics.md`。
- 若涉及断言表（CL-01~11）需要调整，则回到规约修订流程，并用 `_audit_scholar.py` 对全量语料做回归。
- 本目录为数据资产，不含敏感/个人数据。
