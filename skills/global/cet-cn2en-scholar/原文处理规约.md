# 原文处理规约 v1.0

> **地位：四六级汉译英处理链条的「第一规约」。** 汉语原文是最重要的译文依据；翻译教学以读原文为起点。本规约规定：在动笔翻译之前，先把汉语句子做"面向英文构式/词形选择"的功能处理，产出决策依据；译文产出规约在其指导下执行，学理自查规约事后抽检。
>
> 生效：自 **2026.12 批次**起录入统一执行。2026.06 六套样板书为本规约的**回溯试点**（回溯补标 `原文处理` 行），不重译、只补标。
> 本规约由 `学理自查规约.md` v1.2 第 8 节**升格迁出**而来；学理自查规约自此只管**译文侧**一致性抽检。

---

## 1. 定位与总原则

- **输入对象**：汉语原文句子（逐字重建后使用）。
- **产出**：`原文处理` 决策行——说明本句"断句/话题/触发/时锚/逻辑/文化"六类功能点应导向哪些英文候选；它是其后所有译文与标注的**输入依据**。
- **不做**：完整分词 / POS / 依存句法树（功能触发粒度对教学已足够，句法树属研究工具而非教学必需）。
- **宁缺毋滥**：六类均无处理点的句子省略 `原文处理` 行，不硬标、不为凑数加标签。
- **译文多解**：任何原文处理都**不得**声称唯一译法；只列候选集。

## 2. 处理顺序约定（处理先行）

1. **首过**：拿到汉语句后，先做原文处理（六类判定、列候选），再据此产出译文——防止"先看译文再回填标签"的后见之明（post-hoc rationalization）。
2. **回校**：译文定稿后，回校一遍原文处理标签；若译文暴露了更贴切的功能归类，修订标签并记录。两步为"双向校正"，不必等原文处理百分百完成才动笔。
3. **句内位置**：在句子记录块中，`原文处理` 行置于 **译文之前**（紧随句题），以体现其"输入侧"地位；字段顺序见《译文产出规约》。

## 3. 六类判定细则与写法（标签格式 + 示例）

### ① 流水句分断与核心句选择

- 学理：邬菊艳 2023（核心句选择与构建）；崔靓&王文斌 2019；赵朝永&王文斌 2020。
- 判定：以逗号/句号切出分句；信息重心所在分句定为**核心句**；其余分句判定为并列 / 从属 / 状语的候选成分。
- 写法：`断句:分句①…/②…；核心=②；①③→并列|伴随状语(CL-03)|目的(CL-07)`
- 示例：`断句:核心=②；①→时间状语(As…,主句)|介词短语(During…)`

### ② 话题 → 主语（补/换/形式主语/受事被动）

- 学理：马跃珂 2010；Li & Thompson 1976。
- 判定：句首成分是"话题"而非施事主语时，判断英文需**补主语 / 换主语 / 形式主语 it / 受事主语→被动**；句首框架状语（时间/处所话题）亦在此类。
- 写法：`话题:补主语(→Chinese people)|形式主语(It is…)|受事→被动(CL-04)`
- 示例：`话题:句首话题"尊师重教"→提炼为动名词主语(CL-02)|补形式主语(It…)`

### ③ 功能触发词 → SB 候选（多候选核心条）

- 学理：连淑能 1993（使役/强调/目的）；构式语法×翻译（认知构式翻译观）。
- 判定：出现 使/让/得以/随着/近年来/不仅…还/为了/不是…而是/直到…才/并未 等功能触发词，对应触发可迁移构式（L2·SB 候选）；**列候选集而非唯一解**。
- 写法：`触发[使]→enable+A+to do B|allow+A+to do B|make+A+able to do B`
- 示例：`触发[为了]→To+V…,主句(CL-07)|in order to V|so as to V`
- 关联：候选集首选若登记为 L2·SB，按 `学理自查规约.md` 第 7 节执行（骨架+槽位+本句实例）；高频骨架见 `L2·SB_高频句法框架清单.md`（seed）。**"触发词 → SB 编号"反向索引表见该清单「一·附」**——录入时从触发词定位首选 SB，供单句切换 / 命题采样复用。

### ④ 时态 / 体锚点

- 学理：赵朝永&王文斌 2020（时空特质差异）；连淑能 1993（时态呼应）。
- 判定：相传/曾/古代/当时→一般过去；如今/现在/目前→一般现在；近年来/已经/已+了（已然）→现在完成或现在；将/会（表将来）→将来；正在→进行时（依句意择候选）。
- 写法：`时锚:近年来→现在完成|现在一般`
- 无显式锚点词不标（由语境定），避免过度标注。

### ⑤ 意合逻辑关系显式化

- 学理：连淑能 1993（意合→形合）；CL-01。
- 判定：逗号并句之间隐含 并列/因果/转折/条件/让步，需在英文显性化为连接词，列候选。
- 写法：`逻辑:因果→so|as|分句独立`；`逻辑:转折→but|while|whereas`；`逻辑:并列对照→while|and`
- 示例：`逻辑:并列两分句→and(CL-01)|which 非限制定从`

### ⑥ 文化负载词 / 专名识别分级

- 学理：郑德虎 2016；王克非&王颖冲 2016。
- 判定：文化词/专名/固定短语，先查 **固定短语参考库_累积**（源端取证累积库）；有定译或媒体译 → S1 候选；无 → S4 语境通译（允许多候选）；句中出现的术语括注（如原卷括注英文）可作为提示引用。
- 写法：`文化:礼尚往来→S1 reciprocity(媒体)|S4 mutually exchanging courtesies(原卷括注)`
- 关联：直接对接 `固定短语参考库_累积.md` 的查表与新增；词块记录归 `语块 L2·PC`。

## 4. 多候选写法总则与完整示例

- **三级分隔符规则**（类别、子项、候选结构明确分层，避免混用）：
  - **不同功能类别之间**（断句/话题/触发/时锚/逻辑/文化）：用全角 `；` 分隔。
  - **同一类别内的多个子项**（如 `断句` 下的 分句/核心=…/①→…/②→…）：用半角 `;` 分隔。
  - **同一候选点的多个英文候选结构**：用半角 `|` 分隔、**首选在前**。
- 允许为每个候选括注：`S1 定译/媒体`、`S4 通译`、原卷括注、对应 CL/SB 码。
- 完整格式示例（格式示意，非真题录入）：

```
### 句 N <汉语原句>
**原文处理**：断句:分句①…/②…；核心=②；①→时间状语(As…,主句)|介词短语(During…)；触发[使]→enable+A+to do B|allow+A+to do B|make+A+able to do B；时锚:近年来→现在完成|现在一般；文化:直播带货→S1 livestreaming commerce(媒体)|原卷括注 live-streaming commerce
**译文**：…
```

- **省略示例（宁缺毋滥）**：六类均无功能处理点的句子**省略 `原文处理` 行**，不硬标、不为凑数加标签。如"同学们每天坚持晨读。"（施事主语完整、无断句需要、无功能触发词、无显式时锚、无隐含逻辑、无文化负载词）不写 `原文处理` 行，直接 句题 → 译文 → 来源 → 策略/技巧/学理。

## 5. 随行参考库（挂在原文处理之下，不是规约正文）

| 库 | 性质 | 流程归属 | 存储实体 |
|---|---|---|---|
| `固定短语参考库_累积.md` | **源端取证累积库**：以汉语固定短语/文化词为分析对象（原文处理⑥识别）→ 检索 China Daily / 新华 / gov 等官方媒体确认 → 累积"一汉多译"候选英译 | 原文处理 ⑥ + S1 取证链路 | 汉→英对照，键在汉、值在英（expression-level） |
| `L2·SB_高频句法框架清单.md` | 高频句法框架种子库：供 ③ 触发→构式候选时调用与登记 | 原文处理 ③ | 英文构式（schema-level），附中文义/首现/复现/CL 映射 |

> 两库均由原文处理阶段生成/调用：**流程在原文处理（源端），值记录在英文端**；随卷累积、随原文处理生长，不随"译文产出"生长。

## 6. 与其它规约的关系

```
原文处理规约（第一 · 输入侧）   ← 本文件
   ↓ 指导
译文产出规约（第二 · 产出侧）   → 产出 译文/来源/策略L1/技巧L3/语块L2
   ↓ 事后核验
学理自查规约（第三 · 抽检侧）   → CL-01~11 断言，核验译文与 L1/L3 声称一致
```

- 本规约管"从汉语读出什么决策"；译文产出规约管"据决策产出什么译文"；学理自查规约管"产出的译文与标注是否自洽"。
- 三者 + 随行参考库共同构成 `cet-cn2en-scholar` 技能的方法论闭环。
