# cet-cn2en-scholar · 四六级汉译英 · 原文先行 · 三规约闭环

> 本目录是 `cet-cn2en-scholar` 技能（CET-4/6 汉译英学习卡 + 讲义 + 学理标注）的**方法论沉淀**。
> 核心立场：**汉语原文是最重要的译文依据**——动笔翻译前，先对汉语句子做"面向英文构式/词形选择"的六类功能处理，据其决策产出译文，最后做译文侧一致性抽检。官方从不公布标准译文，凡无可靠出处一律如实标注，**绝不伪造或臆造 URL**。
>
> `SKILL.md` 为**机器可调用接口**（触发条件 / 输入约定 / 编排流程）；本 README 为**人读入口**（读完本文件即可掌握整套流程与每条规则的去向）。

---

## 1. 一页看懂：三规约闭环

```
① 原文处理规约（第一 · 输入侧）  读汉语句 → 六类功能处理 → 产出「原文处理」决策行（候选集，多解）
        ↓ 指导
② 译文产出规约（第二 · 产出侧）  按固定字段顺序产出 译文 / 来源S1~S4 / 策略L1 / 技巧L3 / 语块L2
        ↓ 事后核验
③ 学理自查规约（第三 · 抽检侧）  CL-01~11 断言核验「译文与 L1/L3 声称」是否自洽；不解析原文处理行
```

- **第一规约管"从汉语读出什么决策"**，**第二规约管"据决策产出什么译文"**，**第三规约管"产出的译文与标注是否自洽"**。三者 + 随行参考库构成方法论闭环。
- 关键纪律：**处理先行**（先做原文处理再动笔，防后见之明）；**译文多解**（任何原文处理不得称作唯一译法，只列候选集）。

## 3. 处理链条逐环节

### 3.1 原文处理（六类功能点）
| 类 | 判定对象 | 典型输出 |
|---|---|---|
| ① 断句·核心句 | 逗号并句的信息重心 | `断句:分句①②…;核心=②;①→…|…` |
| ② 话题→主语 | 句首话题 / 受事话题 / 无主句 | 补主语 / 形式主语 it / 受事→被动 / 动名词主语 |
| ③ 触发→SB 候选 | 功能触发词 | `触发[使]→enable+A+to do B|allow+…` |
| ④ 时态/体锚点 | 相传/曾/今/近年来/将/正 | `时锚:近年来→现在完成|现在一般` |
| ⑤ 意合逻辑显式化 | 隐含 并列/因果/转折/条件 | `逻辑:因果→so|as|分句独立` |
| ⑥ 文化负载词分级 | 文化词/专名/固定短语 | `文化:礼尚往来→S1 reciprocity|S4 通译` |

- **宁缺毋滥**：六类均无处理点的句子**省略 `原文处理` 行**（不硬标、不凑数）。
- **分隔符**：全角 `；` 为标准（类别间与类别内子项均用）；候选结构用半角 `|`（首选在前）；半角 `;` 仅回溯试点遗留、解析兼容，**2026.12 起统一全角**。

### 3.2 译文产出（固定字段顺序）
`原文（句题）→ 原文处理 → 译文 → 来源 → 策略 L1 → 技巧 L3 → 语块 L2`（**L1/L2/L3 为标注层级，非行序约束**）
- `原文处理` 为句内**首位决策行**；7 标签本体不变，**不新增第 8 一级标签**。
- **来源分级 S1~S4**：
  - S1 官方短语（China Daily/新华/gov/使领馆等**可定位 URL**，仅对应句中短语）
  - S2 编译整句（无逐句官方译文，自整理 → 标"整句无官方译文（整理编译）"）
  - S3 非官方参考（第三方/教育机构/标准库，明示，不作判分依据）
  - S4 未确证·按语境通译（无权威英文源，不得伪装有出处）
  - 铁律：渠道限定、检索可定位、存疑一律降 S4、**绝不臆造 URL**。
- **多解与追加候选**：同一触发点允许多个合法译文；回溯/回校发现更优构式时**追加**为候选，**不删除**旧译文，并可在句内回查到 `原文处理` 决策行（双向可追溯）。

### 3.3 学理自查（译文侧一致性抽检）
- CL-01~11 断言表：策略 L1 / 技巧 L3 文本若提及某学理手段，则译文须体现该手段的**显性特征**（特征词/结构）。
- **红旗机制，非最终判定**：命中=通过（证据可见）；未命中=进入人工复核（区分"断言漏检"与"真实不一致"）。
- **L2·SB 句法框架子类**：类名 `L2·SB`（区别于词块 `L2·PC`），只登记高频且可迁移的骨架（`not only…but also` / `enable…to do` / `To V…目的` 等）；写法=`骨架+槽位+本句实例`；**禁止全句通配误标**；不新增第 8 一级标签。

## 4. 学理出处（避免错挂，速查表）

| 学理点 | 标准出处 |
|---|---|
| 话题/主语凸显 topic→subject | Li & Thompson 1976；马跃珂 2010 |
| 意合→形合、语序重排、修饰语位序、时态呼应 | 连淑能 1993《英汉对比研究》 |
| 翻译评价尺度（自然可读） | Nida 1964 功能对等 |
| 惯用等值 / 词性转换 / 句法转换 | Vinay & Darbelnet 1958；Molina & Hurtado Albir 2002 |
| 语块/词汇法 | **Lewis 1993**（勿挂 Nation） |
| 构式翻译观 / 使役·强调·目的 | 认知构式翻译观；连淑能 1993 |

> 典型错挂规避：把"形合-意合"归 Nida（应归连淑能）；把"语块法"归 Nation（应归 Lewis）。

## 8. 边界与免责

- 技能输出定位为**教学资料**（学生预习/讲义/课堂讲练），**非考场自测学习材料**；译文来源标注依检索当下可得而分级，**不代表官方定稿**，不得作为判分依据。
- 谚语/俗语（如"一日为师终身为父"）无官方标准译法时，一律按 S4 通译并在来源明示，不硬套出处。
- 原文处理为**教学级功能标注**（非完整词法/句法分析），译文允许多解；任何标注不声称唯一译法。
