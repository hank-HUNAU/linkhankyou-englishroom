# 八组自检清单

完稿前必跑 `scripts/bank_qc.py`，八组全绿才算交付。结论写进说明文档第七节（形如"325 项通过、0 项失败"）。

## ① 题量与编号

- [ ] 各题型题量与题量清单一致
- [ ] 总题数一致
- [ ] 编号从 1 起连续、无缺号、无重复

## ② 客观题格式（逐题）

- [ ] 四个选项且字母 A/B/C/D 齐备
- [ ] 选项内容互不重复
- [ ] **选项之间无空行**
- [ ] 单选：答案为单个字母且在选项内
- [ ] 多选：答案为 2—4 个字母、均在选项内、且为升序
- [ ] 四字段齐全：`难易程度／答案解析／知识点／课程目标`

## ③ 答案位置分布

- [ ] 单选答案落在 A/B/C/D 的次数各在 3—8 次之间（无位置偏向）
- [ ] 多选答案组合不少于 4 种

## ④ 知识点唯一性

- [ ] 每道题都有 `知识点：`
- [ ] 全卷知识点两两不重复

## ⑤ 课后习题全覆盖

- [ ] 从 `chapterN_data.js` 的 `exercises` 读出五组，条目数点清
- [ ] 逐个条目的关键词都能在某道题的知识点里命中
- [ ] 术语翻译组：每条术语的英译与课后习题答案**逐条一致**
- [ ] 段落翻译组：各题参考译文拼回后与课后习题答案**逐字一致**
- [ ] 段落翻译组：每句都带中文原句，且顺序与原文一致
- [ ] 思辨讨论组：已改编为写作题（含写作要求、范文、评分要点）
- [ ] 未入卷的条目已在说明文档登记理由与内容承接关系

## ⑥ 交付卫生

- [ ] 无 `TODO／待补／xxx` 等占位残留
- [ ] docx 与 txt 逐段一致

## ⑦ 练习答案词逐项落地

把课后习题填空题、术语简答题的答案词，逐一回到对应题目的**正确选项文本**里核对：

- [ ] 填空 1 的答案词 → 落在对应题正确选项内
- [ ] 填空 2 …（逐条）
- [ ] 术语简答 1／2 的答案要点 → 落在对应题正确选项内

## ⑧ 盘点与说明一致性

- [ ] 说明文档登记的课后习题条目总数与实际一致
- [ ] 说明文档已登记"未入卷条目"及其理由
