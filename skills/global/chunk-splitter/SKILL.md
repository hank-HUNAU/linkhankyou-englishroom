# 句中意群人工切分器（chunk-splitter）

把"句级已经切齐"的音频，在**句内**进一步切成**意群块(呼吸群/chunk)**，产出 CHUNKS 供前端点读/跟读高亮。强调人工放行 + 波形可视化 + 快捷键，UI 友好、操作简单。

## 何时调用

- 用户要为某页生成/精修句中意群 CHUNKS
- 用户提到"句中意群切分、句内切分、切分器、意群块"等
- 需要在切分前用句对齐技能完成句切分（`sentence-alignment`），本技能只处理句内块

## 数据形态

- 输入数据文件（由句对齐流程导出）：`{pg, title, tl, chunks, sents[]}`
  - `tl` = 逐句 `[[start,end],...]`，已由声学引擎保证零串音、句界固定不可改
  - `sents` = 逐句可见文本（用于左侧列表直观定位到句）
  - `chunks` = `{句索引si: [[s,e],...]}`，即本技能要编辑的意群块
- 输出（本技能导出）：`{pg, chunks, tl}` → 存为 edit JSON，交回导入流程注入主应用 `DB.CHUNKS[pg]`
- 配套音频：`{pg}.mp3`/wav，供波形可视化与逐块试听。

## 使用（桌面应用 / HTML 版）

1. **载入音频**：原生对话框选 mp3/wav（或 HTML 版用文件输入），WebAudio 解码后画波形。
2. **载入数据**：粘贴/原生打开导出 JSON，渲染左侧句子列表，跳到 S0。
3. **切分操作**（按句进行）：
   - 点波形任意处 → 在该处落一条意群界（拉开成新块）
   - 拖意群界平移；`吸附谷底`开启时自动吸到 ±0.12s 内能量谷底
   - 底部块胶囊：`×`删除该界；点击选中可用方向键微调
   - 逐块/整句试听，确认切在真实静音谷、不切断词内实音
4. **导出**：点"导出 CHUNKS"生成 edit JSON（含块边界计数），**用原生另存为**存成 `p{pg}_edit.json`。

## 快捷键

| 按键 | 动作 |
|------|------|
| 空格 | 播放/暂停当前句 |
| `]` / `[` | 下一句 / 上一句 |
| Delete(无修饰) | 删除当前选中的意群块(去掉该块界) |
| Ctrl+Backspace | 清空本句所有意群块(需确认) |
| `b` | 试听当前选中块(就地 ±窗口) |
| `g` | 播到当前块末(便于听下一刀口) |
| `z` | 句级缩放 ↔ 整段缩放 切换 |
| Ctrl+O | 打开音频(原生对话框) |
| Ctrl+Shift+O | 打开数据 JSON(原生对话框) |
| Ctrl+S | 导出 CHUNKS 并原生另存为 |
| Shift+→ / Shift+← | 步进 10ms 微调选中块起点 |
| Shift+↑ / Shift+↓ | 步进 1ms 精调选中块起点 |
| 滚轮(或 ctrl+滚轮) | 切 句级缩放 ↔ 整段缩放 |
| 波形左键 | 落意群界(加切点) |
| 波形拖拽 | 拖动已有意群界 |

预期工作流：空格播放→听停顿→点谷底加界→拖准→再播确认→`]` 下一句→Ctrl+S 落盘。

## 导入主应用（数据链路落库）

切分器只产出 edit JSON，不接触主应用。导入由独立命令完成并做多副本一致性校验：

```
python apply_split.py <pg> <p{pg}_edit.json>
```

- 把 `{pg, chunks, tl}` 的 chunks 对象按句索引转成数组，幂等注入所有前端副本的 `DB.CHUNKS[pg]`（已同目标则跳过；无现成赋值则追加到数据字面量之后，不做全文件 JSON 重排）。
- 注入后对每个副本做逐字节 SHA 校验，多副本必须完全一致；任一不同即视为回滚并定位漂移源。
- 前端依赖 `sentence-alignment` 技能的 ③ 归属钳制逻辑（clamp 下界 `max(块起点, 句起点)`）保证 CHUNKS 生效且不破坏点读归属。

## 已入坑

- **键名统一**：CHUNKS 键用 `"p"+padStart(3,"0")`；注入脚本捕获赋值时用 `\["([^"]+)"\]` 保留整键，防止 `p072` 丢 `p` 变成 `072`。
- 句界(绿线)固定不可编辑——只动句内块，句级对齐问题的修复回到 `sentence-alignment` 技能。
- 意群界要放在**真实母语停顿谷**：参考波形能量谷底线（紫），避免切断词内塞音停顿(如 can|kick)，语义略怪但物理真实的停顿可保留。
