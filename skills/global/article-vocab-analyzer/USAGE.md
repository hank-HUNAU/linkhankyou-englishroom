# 使用文档：一篇文章词汇分析技能（article-vocab-analyzer）

本文档说明如何在日常工作中**自动调用**本技能，并分别支撑 **教师教学材料生成** 与 **学生自主学习材料生成** 两条生产线。

---

## 1. 技能能做什么（一句话）

输入任意英文课文/句库，自动分词并按 **KET < PET < NGSL < NAWL** 四词表判定每个词的最低归属层，输出：

- 各词表命中覆盖率（达标线：token 覆盖 ≥95% 方具"可独立阅读"前提）
- 归属分层闭环（每词只归一层，不重叠：KET / PET / NGSL / NAWL / 超纲 out）
- 每词条：词性 / 频次 / 跨句 Range / 原文例句 / 可选 CEFR
- 附赠逐 token 结构化 JSON + 可跨文章累积的词汇库（SQLite + Excel 视图）

---

## 2. 何时触发本技能（自动调用前判别）

以下任一情形即可调用，无需指定任何代码细节：

| 触发信号（用户一句话） | 我自动判断并执行 |
|---|---|
| "这篇课文属于哪个词汇层 / 命中率多少" | 全文词汇分层 + 覆盖率 |
| "给基础段学生圈出该读的词（KET/PET 不足）" | 输出全员层词卡（KET/PET） |
| "给中/中强段挑进阶词（NGSL/NAWL/超纲）" | 输出中/强层词卡补卡清单 |
| "这篇文章有多难 / 超纲词有多少" | 难度剖面 + 超纲词清单 |
| "给这些词标 CEFR / 标难度等级(A1-B2)" | 内置 Oxford CEFR 标签(无需联网) |
| "帮我积累历次阅读的高频词 / 建词汇库" | `--db` 入库 + 累积导出 |

**我会按需组装命令行**，例如：

```bash
# 一键(推荐,防健忘): 分析+入班库+导出三视图, 只传源即可
python scripts/vocab_run.py 课文.txt
python scripts/vocab_run.py 课文.txt --doc "课次A-课文1"

# 全文分析（备课评估）
python scripts/assess_vocab.py --file 课文.txt --out 课文评估

# 分析 + 累积入库（跨单元建班词库）
python scripts/assess_vocab.py --file 课文.txt --db vocab.db --doc "课次A-课文1"

# 累计后导出教师/学生视图
python scripts/assess_vocab.py --file 课文.txt --db vocab.db --db-export bank_views.xlsx
```

> 你不必记住这些参数。只要说"分析课文""建词汇库"或"导出词卡"，我就会代你填好。

## 3. 教师教学工作流（备课 · 命题 · 补卡）

### 3.1 从课本句库批量分析
推荐把课本句库整理成一列（`篇/序号/文本`），一次性喂给技能：

```bash
python scripts/assess_vocab.py --xlsx 教学.xlsx --sheet "C4 句库时间轴" --col 2 --out 单元评估
```

输出 `单元评估.xlsx`，教师据此：
- **选听写目标词**：挑 NGSL/NAWL 层、Range 适中、例句饱满的词。
- **划考点层**：把"全员(基础)"与"中/中强(进阶)"分开，直接映射到班内分层教案。

### 3.2 累积建库 + 分档补卡（推荐，用 `--db`）
每次备课带上 `--db vocab.db --doc "课次-篇名"`，词汇库自动累积：

```bash
python scripts/assess_vocab.py --file 课文.txt --db vocab.db --doc "课次A-课文1"
python scripts/assess_vocab.py --file 课文.txt --db vocab.db --doc "课次B-课文2"
```

积累几篇后导出视图：

```bash
python scripts/assess_vocab.py --file 课文.txt --db vocab.db --db-export bank_views.xlsx
```

`bank_views.xlsx` 三张表对应三种教学动作：

| Sheet | 内容 | 教师动作 |
|---|---|---|
| 分层词卡 | 按层汇总的跨篇词卡（含频次/出现文章数/例句） | 出分层重点词表 |
| 补卡清单 | out/NAWL 词，按"出现文章数"降序 | 跨篇反复出现的进阶词优先补 |
| 研究覆盖 | 每次入库的文章×词表来源×时间 | 追踪各班积累进度、回溯材料 |

> 记忆点：`n_doc`=该词出现在多少**不同文章**中，跨篇越多次越该优先讲；`freq`=累计 token 频次（含同篇多次）。

### 3.3 命题合规提醒
- KET/PET/中高考真题受版权保护 → 只做 **同构仿真题**，勿照搬真题。
- 词表命中 ≠ 成题：完整出卷还需语法梯度、难度校准（IRT/Rasch）、信效度检验。

## 4. 分析结果如何用于编写教学与学习资料

本技能只做**通用分析**并交付结构化结果；具体教学/学习资料的版式与界面属你决定，不由技能预置。分析结果可按需供给两类资料：

### 4.1 供教师编写教学资料
- **分层词汇卡**：按 KET/PET/NGSL/NAWL 分层出词，对应基础/中/中强教学梯度。
- **频次与 Range**：跨句广度与频次辅助选定听写目标词、重点讲读词。
- **超纲/进阶词**：NAWL 与超纲词作补充讲解与备选补卡清单。

### 4.2 供学生编写学习资料
- 把 `vocab_report.json` 的逐条结果（`lemma/layer/cefr/示例例句`）作为数据源，接入你自己设计的学习界面或习题页。
- 例句字段可直接取自原文原句，交付学生记忆/听写材料。

### 4.3 生成步骤（由我代劳）
1. 你提供课文文件 / 句库 xlsx / 一段文本。
2. 我运行分析（可按 `--out 教师版` / `--out 学生版` 分开出件）。
3. 我交付分层词卡、覆盖率、超纲清单及结构化 JSON，你据此编写教学或学习资料（含是否叠加 `--db` 累积库）。

## 5. 输入输出速查

| 输入 | 含义 |
|---|---|
| `--text "..."` | 直接给文本 |
| `--file 课文.txt` | 读 .txt/.md |
| `--xlsx 教学.xlsx --sheet S --col N` | 读某工作表某列（0 基列号） |
| `--stdin` | 管道输入 |
| `--cefr cefr.json` | 附加 CEFR 难度标注 |
| `--out name` | 自定义输出名（默认 `vocab_report`） |
| `--db vocab.db` | 累积入库（与下文 `--db-export` 联用效果佳） |
| `--doc "标识"` | 入库文章标识（缺省用文件路径 / 时间戳） |
| `--db-export 视图.xlsx` | 从词库导出「分层词卡 / 补卡清单 / 研究覆盖」 |
| `--mwe` | 附加候选短语提取，输出「候选待核短语」页签（可写入 phrase_extra.json） |

**输出**
- `<out>.xlsx`：覆盖率 + 每词表命中明细 + 超纲词 + 归属分层闭环 + 专名词表（地名/机构/物名等首字母大写词，认识清单，零联网）
- `<out>.xlsx`（`--mwe` 时）：另含「候选待核短语」页签（N-gram+MI 打分，核注后写 `wordlists/phrase_extra.json`）
- `<out>.json`：逐 token 结构化（`kind/lemma/hit/layer/cefr`），供学习界面消费
- `vocab.db`（可选）：跨文章累积词库
- `bank_views.xlsx`（可选）：教学/研究视图

---

## 6. 边界与口径

1. 覆盖 ≥95% token 才算"可独立阅读"，不是只报百分比。
2. NGSL/NAWL 无词性，命中明细中其词性列留空属正常。
3. 同形异义词（found/left/rose）自动分析后建议人工复核。
4. CEFR 是有序轴，统计须用秩相关/有序回归，勿当连续数加总。
5. CEFR 可落地来源：CEFR-J 下载 + 词典星标（Oxford 3000/5000）。
