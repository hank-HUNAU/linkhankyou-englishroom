# 一篇文章词汇分析 · 词表体系技术文档

> 适用范围：基于九层词表（**少儿底表 Pre A1/A1/A2**（剑桥少儿官方）+ **考点阶梯 KET(A2)/PET(B1)/FCE(B2)/CAE(C1)** + **频率/语体 NGSL/NAWL**）与 CEFR 难度框架，对任意英文文章进行词汇分析、教学设计与科研统计。
> 数据基础：`E:\vocabulary profiler\` 下 KET、PET、NGSL、NAWL 三件套文件。

### 1.1 结构说明

每套词表由三个文件组成，结构不完全同构：

| 文件 | 用途 | KET/PET | NGSL/NAWL |
|---|---|---|---|
| `_head.txt` | 纯词头清单（去重） | ✅ | ✅ |
| `_for_teaching.csv` | 教学版：词头+词性+例句+常用词形 | ✅ 有词性例句 | ❌ 仅词头+词形 |
| `_for_research.csv` | 研究版：词头+全部屈折词形 | ✅ 合并多词性 | ✅ |

### 1.2 KET 词表（Cambridge A2 Key）

- **学理定位**：A2 "基础沟通"层的**考试词汇构念**，覆盖 KET 考试题型词汇面。
- **功能**：划定英语生存沟通核心词区；判断文章是否为"基础层适读"。
- **教学**：服务"全员"分层目标词；例句为课本原句照搬。
- **科研**：考试效度检验、CEFR 锚定（KET ≈ A2，官方锚点）。

### 1.3 PET 词表（Cambridge B1 Preliminary）

- **学理定位**：B1 "独立使用者"进阶层的**考试词汇构念**。
- **功能**：在 KET 未命中的词上追加覆盖，构成"基础→进阶"两级递进。
- **教学**：服务"中/中强"分层目标词、真题扩展词卡。
- **科研**：同 KET，锚定 B1；层间递进增量可测。

### 1.4 NGSL（New General Service List）

- **学理定位**：**通用高频词族表**（约 2800 词族），按语料**频率**而非难度排序。
- **关键属性**：内部词可横跨 A1–C2（如 *abandon* 高频但难、*a/an* 极基础）。**它是频率表，不是难度表。**
- **教学**：高频先学、低频后学的教学顺序；通用英语目标词集。
- **科研**：Range / AntWordProfiler 标准输入，做 token/lemma 双口径覆盖统计。

### 1.5 NAWL（New Academic Word List）

- **学理定位**：**学术语体词族表**（约 960 词族），横跨学科，整体偏 B2+。
- **功能**：与 NGSL 构成学术文本两段式覆盖（通用高频打底 + 学术词上浮）。
- **教学**：学术英语（EAP）差异化目标词集。
- **科研**：文本"学术化程度"的连续代理指标。

### 1.6 九层关系

```
A1_Starters ⊂ A1_Movers ⊂ A2_Flyers → KET(A2) ⊂ PET(B1) ⊂ FCE(B2) ⊂ CAE(C1) → NGSL(通用) → NAWL(学术)
   少儿入门层                        └───── 考点阶梯（A2→C1）─────┘        通用高频层    学术层
```

**四类用途**：少儿底表答「是不是入门词」；KET–CAE 答「考不考 / 属哪个考点层」；NGSL 答「常不常用」；NAWL 答「学不学术」。

## 2. CEFR 的作用与功能

### 2.1 它是什么

- CEFR 本身**不是词表**，是**能力描述体系**（A1–C2 六级，描述"会做什么"而非"会多少词"）。
- 由 CEFR 派生的**官方分级词表**为 **EVP**（English Vocabulary Profile，剑桥，约 6600 词，A1–B1 逐词定级，区分词性义项）。
- 官方 EVP **不提供整表下载**，仅在线逐词查询；可落地替代：**CEFR-J**（可下载）与词典 CEFR 星标（Oxford 3000/5000）。

### 2.2 对文章做什么

- 对文章全部实义词**逐词标注 A1–C2**，产出**难度分布曲线**，给出适读难度判断。
- CEFR 与九层词表**正交独立**：同一个词可同时有"归属层 = PET"与"难度 = B1"。

### 2.3 边界（重要）

- **九层词表内部不需要 CEFR**：KET≈A2、PET≈B1 已由剑桥官方锚定；NGSL/NAWL 非难度轴，强行逐词标 CEFR 是循环论证 / 硬套不存在的维度。
- CEFR 坐标**前段可信（EVP）、后段偏近似**（B2–C2 无官方整表，靠词典星标）。
- 标定顺序：EVP 精确查 → 词典星标 → **仍缺留空不猜**。

## 3. 一篇文章词汇分析工作流程

### 3.1 输入与预处理
1. 取文章（文本 / PDF / 截图），清洗格式残留。
2. **分词 + lemma 归一化**（runs→run，children→child），保留原文 token ↔ 屈折形式映射。

### 3.2 词项分流（优先级从高到低）
3. **短语优先**：多词单元（in front of、alarm clock）整体命中，再切单字，避免拆碎误判。
4. **专名/数字分流**：人名地名、数字、缩写单列，不进难点统计。

### 3.3 九层词表命中与归属
5. 逐层命中 `KET → PET → NGSL → NAWL`，按**最低级别只归一层**（KET 优先生效），保证各层覆盖率闭环不重叠。
6. 分层：基础 KET / 进阶 PET / 通用 NGSL / 学术 NAWL / **超纲**。
7. 命中词回查教学版 CSV，配**课本原句照搬**例句。

### 3.4 CEFR 难度标注（独立正交模块，可开关）
8. 对实义词（含超纲词）逐词标 A1–C2，来源优先级 EVP → 词典星标 → 留空。
9. 生成难度分布曲线，判定适读难度。

### 3.5 统计与报告
10. 双口径覆盖率（token / lemma）+ Range 指标（HRWR / C 值）。
11. 超纲词分类清单：专名/数字（豁免）、学术低频、真超纲（建议替换或补卡）。
12. 输出 Excel 多标签页：词汇卡（词头+词性+原句照搬+归属层+CEFR 难度+屈折形式）、覆盖统计、超纲词、难度剖面。
13. 可选：分层教学任务（全员/中/中强）。

## 4. 各词表的学理定位与预测边界

### 4.1 语体预测：NGSL / NAWL

- **能预测"学术 vs 通用"这一特定语体维分化**，不能预测全部语体。
- **原因**：语体（register）是多维构造（Biber, 1988 多维分析法，至少 6 个功能维度：信息性、叙述性、交互性、明确性、劝说性、抽象性）。口语/书面、正式/非正式、叙事/说明更多由**句法、语篇标记、情态**决定，词汇只是其中一个维度。
- **判别模式**：NAWL 高覆盖 + NGSL 相对低 → 强学术语体；NGSL 高 + NAWL 极低 → 通用语体。
- **边界**：NAWL 覆盖率是"学术化程度"的**连续代理指标、强判别信号**，但**非充分判据**（还需句法/语篇佐证）。

### 4.2 语体预测模型（可落地）

- **特征层**：句法（被动、关系从句、名词化、that-补语）、语篇（连接词、指代衔接）、情态（情态动词、祈使、疑问）。
- **工具**：
  - Biber 标签器（6 功能维度打分）
  - Coh-Metrix（Graesser et al., 2004，自动化多维文本特征）
  - 监督学习分类器（SVM / 随机森林，Biber & Egbert, 2018 register classification）
- **本质**：预测的是**"维度位置"**（双极连续坐标），而非语体字典里的一个类型名。

### 4.3 考试等级预测：KET / PET 与中高考词表推广

- KET/PET 词表 = A2/B1 考试的**词汇构念**，对文章的命中率即该文对该考试的**词汇适配度**。
- **推广逻辑成立**：中高考词表同为"考试词汇构念锚点"（中考 ≈ A2 上下，高考 ≈ B1–B2 之间），可作平行探针。补入中高考词表即可把预测体系从"剑桥双表"扩展到"中国课标双表"。
- **学理根基**：Hu & Nation (2000) "覆盖率→可读性"假说 + 测试构念映射（test-spec mapping）。

### 4.4 据此设计备考题目

- **能做的**（词汇维度内）：选文词汇校准、生词控制（lexical coverage control, Nation 2001）、词汇题命题来源（词义/拼写/搭配）、完形/阅读可理解性基准。
- **学理**：构念效度（construct validity）、测试规范（test specification）、词汇测试学（Read, 2000，目标词 vs 支撑词之分）。
- **必须守住的边界**：不能复制真题（版权）；词表 ≠ 完整命题逻辑（还需语法梯度、难度校准 IRT/Rasch、信效度检验）；中高考命题权在官方，走"自编仿真练习"路径。

## 5. CEFR 难度坐标详解

### 5.1 坐标性质

- **类型**：**有序分类轴（ordinal categorical scale）**——A1 < A2 < B1 < B2 < C1 < C2 严格有序。
- **非等距**：B1→B2 的难度差 ≠ A1→A2，**不能当计分尺做加减乘除**。
- **定义单位**：**can-do 语句**（能做某事），非词频或正确率。
- **锚定对象**：学习者能力谱系（某级学习者语料普遍产出的词），而非词本身。

### 5.2 标定来源

| 段 | 来源 | 说明 |
|---|---|---|
| A1–B1 | **EVP**（剑桥，学习者语料+教材语料） | 逐词定级，最权威 |
| B2–C2 | 词典 CEFR 星标（Oxford 3000/5000） | 近似，非官方整表 |

### 5.3 坐标能解释什么

1. **适读性门槛**：文章词汇分布在哪级 → 对哪级学习者适读/超限/偏易。
2. **可理解输入（Krashen, 1985, i+1）**：教学选文落在学习者当前级 +1。
3. **发展路径**：把词按等级切片 → 学完这篇词汇实力推进到哪一级。
4. **难度 ≠ 频率**：一个高频词可能 CEFR B2（如 *abandon*），校正"高频=易"的直觉。

### 5.4 教学与科研用途

| 用途 | 教学 | 科研 |
|---|---|---|
| 选材分级 | 文章按词汇剖面打级入库 | 文本/试题难度标注的统一坐标 |
| 定级分班 | 等级检测分班 | 跨文本/考试/学习者比较 |
| 目标设定 | can-do 目标 | 可读性建模特征输入（结合 Lexile/词频） |
| 评估 | 形成性检测、指明下一级 | 学习者词汇发展轨迹追踪 |
| 验证 | — | 考试等级匹配的构念效度证据 |

### 5.5 统计要点（易踩坑）

CEFR 是**有序分类轴**，统计上必须用**有序/非参数方法**（秩相关、有序分类回归），**不能把 B1=2、B2=3 当连续变量做普通回归或加总**。

## 6. 教师视角：词表对一篇文章能做什么

**"读懂—教得—练得—测得"**：

1. **读懂难度（选文）**：九层覆盖 + 超纲比 → 判断适读层。
2. **定考点分层（备课）**：KET→全员基础词，PET→中/中强进阶词，NGSL/NAWL/超纲→扩展补充卡；配课本原句照搬例句。
3. **设计任务（出题）**：词表当"命题词汇规格书"，控超纲比，按研究版词形出词形变化练习；自编仿真题，不复制真题。
4. **测与跟踪（评估）**：同表回测，定位"差哪个层"，文章变成可追踪的词汇检测节点。

## 7. 学生视角：记忆词汇需要的数据

按 Nation (2001) "形式–意义–使用"三分维度，按优先级：

| 优先级 | 数据项 | 理由 |
|---|---|---|
| ★★★ | **完整原句照搬** | 情境记忆，最利于提取 |
| ★★★ | **词性与本义** | 建立 form-meaning 连接 |
| ★★★ | **屈折/词形变化** | 从句法上用起来 |
| ★★ | **同源派生 1 个** | 打通词族，成串记 |
| ★★ | **英-英简义或译文** | 建立语义连接 |
| ★★ | **真实发音（音标+音频）** | 音形义三通道编码 |
| ★ | **难度锚点**（CEFR 级/归属层） | 设预期、不焦虑 |
| ★ | **典型搭配 1–2 例** | 产出更地道 |

**记忆学理**：
- **输入频率**（Ellis, 2002）：复现次数是第一预测变量 → 备课时让考点词多复现。
- **间隔重复**：后续课次/测试再见才能进长时记忆。
- **加工深度**（Craik & Lockhart, 1972）：听读写用多通道触达记得牢。

> 理想的学生词汇数据 = **原句 + 词性 + 词形 + 派生 + 音义 + 难度锚点**，靠**复现 + 间隔重测**钉进长时记忆。

## 9. 边界与注意事项

1. **版权**：KET/PET 真题受剑桥版权保护，可参考词表**自创同构仿真题**，不可照搬；中高考同理。
2. **词表 ≠ 完整命题逻辑**：完整出卷还需语法梯度、难度校准（IRT/Rasch）、信效度检验。
3. **覆盖阈值**：学术共识 ≥95% token 覆盖才具备"可独立阅读"前提。
4. **同形异义词（homograph）**：NGSL 自身标注了 found/left/rose/wound 等问题，自动分析需人工复核或上下文消歧。
5. **多词单元（MVU）**：命中顺序上短语先于单词，否则被拆碎误判超纲。
6. **lemma 归一化质量**：直接影响覆盖率数字，须固定归一策略（研究版词形正好支撑）。
7. **CEFR 统计口径**：有序分类轴，用非参数方法，不可当连续变量。
8. **EVP 数据获取**：官方不提供整表下载，可落地来源为 CEFR-J（可下载）+ 词典星标。
