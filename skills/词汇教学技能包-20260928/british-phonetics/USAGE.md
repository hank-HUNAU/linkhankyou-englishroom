# 使用文档：英式语音语调（british-phonetics）

> 把一篇文章做成**英式发音 / 朗读跟读**材料：逐词英式音标 + 真人发音 + 原句朗读标注。
> 说一句意图即可，参数由 AI 代填，不必记。

**定位**：`article-vocab-analyzer` 主技能的**发音分支**。与 `student-vocab-cards`（词义记忆）分工，本技能只取**发音维度**，默认英式。

---

## 1. 快速开始

```bash
# 一条命令：课文文件 → 三页签 Excel
python scripts/phonetics.py --file 课文.txt --out 攀登者朗读卡
```

| 步骤 | 做什么 |
|---|---|
| ① 准备 | 待分析的英文课文（`.txt` 或直接 `--text`） |
| ② 运行 | 上面的命令（联网取音标+发音） |
| ③ 得到 | `攀登者朗读卡.xlsx`（三页签）+ `攀登者朗读卡_tts/` 音频包（真人发音已下载为本地 mp3，随 xlsx 一起用） |

**前置条件**

- 已安装主技能 `article-vocab-analyzer`（本技能复用其分词/分层/原句结果）。
- Python 环境含 `openpyxl`；用 `--voice gb-*` 选性别发音时另需 `edge_tts`。

## 3. 输出物：三页签逐列说明

### 页1 · 原句朗读标注

按**意群**把每个原句逐词一列铺开，每句占 **3 行 + 1 空行**：

| 行 | 内容 |
|---|---|
| 音标行 | 该词的英式音标，与词**同列上下对齐**；**只标实词**，虚词留空（虚词看页3弱读表） |
| 原文行 | 原句逐词 |
| 意群行 | 每个意群段合并单元格，居中放 `⊣停顿` / `∨降调` / `∧升调` |

- 完整原句照搬，不截断；同一句只出现一次。
- 教师：领读时先按意群断句，再提示升降调。学生：跟节奏朗读。

### 页2 · 单词英式音标

| 列 | 说明 |
|---|---|
| 词汇 | 词目 |
| 教学梯度层 | 全员(基础) / 中阶 / 中强 / 中强(超纲·进阶)（依 KET·PET / NGSL / NAWL / 超纲 分层） |
| 词性 | 原句中的词性 |
| 英式音标UK | UK IPA（剑桥分音节式优先，缺则有道） |
| 重音提示 | 主重音 / 次重音 / 单音节·重音在首（据音标 `ˈ` `ˌ`） |
| 弱读/朗读提示 | 虚词弱读形式（如 to→tə、of→əv） |
| 英式真人发音 | 本地 mp3 文件名（真人发音已下载），**可直接点开播放** |
| 音源 | 本地mp3(真人·下载) / 剑桥真人(URL) / 有道英音(URL) |
| 原文照搬 | 该词所在的完整原句 |

### 页3 · 语音讲授要点

- 弱读规则、强/弱读切换、重音位置、升降调、停连示范（含示例）。
- 附**本课弱读词表**：只列本课文实际出现的功能词及其弱读形式。

## 4. 参数速查

| 参数 | 作用 | 默认 |
|---|---|---|
| `--file 课文.txt` | 输入：课文文件 | — |
| `--text "..."` | 输入：直接给文本 | — |
| `--out 名` | 输出文件名（生成 `名.xlsx`） | `英式语音卡` |
| `--voice youdao\|gb-male\|gb-female` | 发音来源：下载剑桥→有道真人发音 / 英男 / 英女 | `youdao` |
| `--limit N` | 只对前 N 词联网取音（防限流 / 快速出稿） | 全部 |
| `--offline` | 断网：只出静态朗读标注，不取音标音频 | 关 |
| `--no-cambridge` | 关闭剑桥主源，只用有道 | 关 |
| `--no-tts` | 禁用 TTS 兜底（词典下载不到即留空，非交互/管道用） | 关 |

`--voice` 明细：

- `youdao`（默认）→ **下载剑桥真人发音为本地 mp3**；剑桥下载不到兜底有道下载；两源都无则提示**经确认才**用 edge_tts（TTS 仅备用）
- `gb-male` → 英式**男声**（edge_tts en-GB-RyanNeural / ThomasNeural），直接生成本地 mp3
- `gb-female` → 英式**女声**（edge_tts en-GB-LibbyNeural / SoniaNeural），直接生成本地 mp3

## 5. 音标与发音来源

**取音链路：剑桥首选 → 有道兜底**

- **英式音标（首选）**：剑桥词典抓取 API（`dictionary-api.eliaschen.dev`，Cambridge en-cn 分音节式 RP 音标）+ 官方真人音频 URL。
- **英式音标（兜底）**：剑桥 404 / 缺词条时，自动回退有道 `ukphone`（英式 IPA）。
- **英式发音（默认下载为本地 mp3）**：**首选剑桥真人音频并下载为本地 mp3**；剑桥下载不到自动回退有道 `dictvoice?type=1` 下载。两源均为真人录音、**均不区分男女**；若两源都取不到音频，默认提示并**须确认**才走 edge_tts（TTS 仅备用）。产出 `→<out>_tts/` 本地音频目录。

**专名补音（A + B + 自学习）**——人名等词典不收的专名：

1. **内置读音库** `scripts/names_ipa.json`：约 180 个常用英美名/姓的英式 IPA，开箱即命中。
2. **人工核注表** `NAMED_IPA`（脚本顶部）：课文特有专名在此核注一行即自动标音。
3. **库自学习回写**：凡新解析出音标但库中缺的专名（含教师核注的新专名），运行结束自动回写 `names_ipa.json`，下次开箱即命中。

若仍有专名**补不出音标**，控制台打印「待核注专名清单（原文 ×频次）」，照抄进 `NAMED_IPA` 换成真实音标，重跑即全绿。

**精度口径**：页1 标的是**纸上那个词**的读音，故屈折形（waited / climbing）取**表层精确音**；词目词才走剑桥首选。

## 6. 三种典型用法

**① 课前出一份发音 / 跟读材料（最常用，默认已下载发音）**

```bash
python scripts/phonetics.py --file 课文.txt --out 攀登者朗读卡
# 真人发音默认下载为本地 mp3 → 生成 攀登者朗读卡_tts/ 目录，随 xlsx 一起用
```

**② 要英男 / 英女性别发音（课堂示范）**

```bash
python scripts/phonetics.py --file 课文.txt --voice gb-female --out 英女跟读卡
# 会在脚本旁生成 英女跟读卡_tts/ 音频目录，需随 xlsx 一起拷走
```

**③ 大课文防限流 / 断网赶稿**

```bash
python scripts/phonetics.py --file 课文.txt --limit 30   # 先出前 30 词，分批补
python scripts/phonetics.py --file 课文.txt --offline    # 断网：只有朗读标注
```

## 7. 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 某专名没音标 | 词典不收人名。控制台会列「待核注专名清单」，核注进 `NAMED_IPA` 后重跑 |
| 页1 某些词上方空白 | 虚词（the/is/of…）按设计**不标音标**，看页3弱读表 |
| 发音点开是本地文件名 | 默认即下载为本地 mp3，需把 `<out>_tts/` 目录与 xlsx 一起移动 |
| 某词发音列留空 | 剑桥+有道都下载不到，且非交互（未确认 TTS）；需则用 `--voice gb-*` 显式生成 |
| 取音变慢 / 中断 | 逐词联网限流，改 `--limit N` 分批；或 `--offline` 出静态稿 |
| 剑桥音标与有道不一致 | 剑桥为首选；要统一用有道加 `--no-cambridge` |
| `完成: … 英标覆盖 K 词` | K 小于总词数说明有词未取到音标（多为专名/超纲），按清单补 |

## 8. 边界与注意事项

- **需联网**：音标/发音来自剑桥、有道、微软；断网用 `--offline`。
- **第三方剑桥 API 为个人维护**，可能限流或变动；已做主源并有有道兜底，不稳定时可用 `--no-cambridge` 完全绕开。
- **真人发音默认下载为本地 mp3**：`<out>_tts/` 目录需随 xlsx 一起转移；`--voice gb-*` 同为本地 mp3。断网/离线无下载。下载不到且非交互时音源列留空。
- **TTS 仅备用且需确认**：剑桥+有道都取不到音频时才提示用 edge_tts，且须交互确认；管道/自动化默认 `--no-tts` 禁用。
- **启发式语调**：升降调、停连是自动化建议，是朗读起点，请对照原声音频与真人示范把关。
- **弱读表**为常见功能词，个别词因语境需强读，由教师取舍。
- **版权红线**：真题只做同构仿真，不照搬。

> **整合提示**：本脚本产出的 `<out>_*.xlsx` 会被主技能 `scripts/vocab_merge.py` 拾取，整合为 `<out>_教师版.xlsx`（权威合集）与 `<out>_学生版.xlsx`（学习向页签）；或由 `scripts/vocab_pipeline.py` 一键串联自动整合。
