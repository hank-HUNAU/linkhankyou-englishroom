# 使用文档：学生记忆词卡（student-vocab-cards）

面向**学生自主学习**的软分支。复用主技能 `article-vocab-analyzer` 的分层结果，逐词联网（有道 + 剑桥）补全**记忆所需全部字段**，输出一张学生自学的记忆词卡 Excel。

---

## 1. 一句话定位

给每个词，从"只会认"补到"记得住、读得准、看得懂"：原文原句（照搬）+ 该词在原句的词性 + 本义 + 音标 + 真实发音 + 英英简义 + 派生 + 双语例句。**词义按原句语境自动收敛**，不列一长串无关义项。

---

**我自己组装命令行**：

```bash

python scripts/student_cards.py --text "..." --out 卡
python scripts/student_cards.py --file 课文.txt --layer-filter KET,PET   # 只挑基础层

```

## 3. 输出（Excel 四个工作表）

**① 学生记忆卡（14 列，按 lemma 聚合）**

| 列 | 内容 |
|---|---|
| Word | 词（去重 lemma） |
| 归属层 / CEFR | KET/PET/NGSL/NAWL/out + CEFR；CEFR 空时回退剑桥徽标 |
| 原句照搬 / 原句词性 | 课文原句 + 该词在原句单一词性 |
| 例句词形 | 该 lemma 在**原句中实际出现的词形**（如 go→went） |
| 例句本义 / 例句义·英英 | 该词性**首条**中文义（词典序）+ 剑桥英英首条 |
| 其他词形 | 本文该 lemma 其他屈折形 |
| 本义扩展·其他义项 | 该词性其余义项（作扩展） |
| 音标 / 发音音频 | IPA + 真实发音链接（有道为主，剑桥兜底） |
| 派生词 / 双语例句 | + 同源派生 + 英中对照(≤3条) |

> **单形单义优先**：卡片首条对齐例句（例句那一处的一个词形一个意思），其余作扩展。

**② 实词表 / ③ 虚词表**（听写·默写抽查）
- 字段：`词 | 例句词性 | 英文含义(剑桥英英) | 中文含义 | 原文例句 | 译文`
- 实词 = n/v/adj/adv/num；虚词 = 介词/代词/冠/连/情态等

**④ 专名词表**（认识清单）
- 字段：`专名 | 频次 | 中文义(有道 ec 首条)`
- 地名/机构/物名等首字母大写专名单词，认识常见专有名词；人名有道无专名语义，属预期留待核注

---

## 4. 词义消歧（本分支核心，两级）

1. **第一级·按原句词性过滤**：对原句做轻量 POS 标注，只保留该词性的义项，滤掉跨词性无关义（如 `show` 在原句为名词 → 只取"节目/展出"义）。
2. **第二级·同词性内按原句搭配选义**：若该词性仍有多个义项，用原句里的实义搭配词，与词典例句匹配，挑最贴近原文语境的义。

> 学生看到的"本义"是贴近原文语境的那一条，而非整页词条。

---

## 5. 与主技能 / 教师版的关系

| 需要 | 用哪个 | 说明 |
|---|---|---|
| 通用分析/覆盖率/难度剖面 | 主技能 article-vocab-analyzer | 底层引擎，两分支都复用它 |
| 学生记忆词卡（本分支） | student-vocab-cards | 联网补词典，字段最全，逐词较慢 |
| 教师备课本（命题/挖空/词卡） | teacher-vocab-prep | 静态、零联网、快 |

**分工**：备考深度用 teacher（快）；生成学生自学材料用 student（联网补全）。

---

## 6. 边界（务必读）

1. **需联网**：本分支逐词查有道+剑桥，受词典限流影响，**整篇批量联网可能卡/慢**——遇此自动用 `--limit` 分批处理。断网时用 `--offline` 退回静态结果。
2. **超纲词(out)无原句**，故"原句照搬/原句词性"为空属正常（仍给本义/音标/简义）。
3. **英英简义来源**：有道简义有限，主要取剑桥；剑桥对该词无词条时该项留空。
4. **版权红线**：KET/PET/真题仅参考词表自创同构仿真题，不照搬真题原文作素材。
5. **不预置版式**：本分支只交付结构化记忆卡数据；专属界面/翻卡版式由你二度加工。

---

## 7. 防健忘话术口诀

- 出词卡 → `给学生记忆词卡`
- 只要基础层 → 说清"只要 KET/PET"
- 卡太慢/批量卡 → 自动分批 `--limit`
- 断网 → 说"离线出静态"即可

> **整合提示**：本脚本产出的 `<out>_*.xlsx` 会被主技能 `scripts/vocab_merge.py` 拾取，整合为 `<out>_教师版.xlsx`（权威合集）与 `<out>_学生版.xlsx`（学习向页签）；或由 `scripts/vocab_pipeline.py` 一键串联自动整合。
