# 学生记忆词卡（student-vocab-cards）

本技能是 **article-vocab-analyzer 主技能的软分支/后处理**：不重复分词与分层，而是复用主技能产出的"唯一 lemma + 归属层 + CEFR + 原句 + 词性"，再逐词调在线词典补全学生记忆所需数据，汇成学生可自学的词卡。

## 定位

- **复用主技能**：脚本内自动赋值 `ASSESS`——优先取脚本同级平铺的 `assess_vocab.py`（开发/工作区态），否则沿目录向上查找部署位的 `article-vocab-analyzer/scripts/assess_vocab.py` 及其 wordlists，主技能升级分支自动受益。
- **在线词典后处理**：对命中词调有道词典 `dict.youdao.com/jsonapi` 补全释义/音标/音频/派生/例句，调剑桥 `dictionary.cambridge.org/dictionary/english` 补英英简义与 CEFR 徽标。
- **两级词义消歧**：①先按原句词性过滤（独立成节见下）；②再在同一词性内用**原句搭配实义词**与各义项词典例句做**搭配匹配**，选出最贴近原句语境的义项。无搭配命中时保留该词性下前几条义项。
- **本义收敛**：有道中文本义只取该词性下前 2 个义项的**首个"；"子义**，并剔除专名（人/地名）义项，避免一张卡片塞满整串词典释义。

## 按原句词性过滤（词义消歧·第一级）

**核心规则：一个词在原句中只承担一个词性；只保留与该词性匹配的词典义项，剔除跨词性的无关义项。**

实现机制：

1. **原句词性裁定**：对原句做轻量 POS 标注（nltk `averaged_perceptron_tagger_eng`，公式中该词出现的形式及其屈折形式均参与），得该词在原文中的单一基础词性（如 `n / v / adj / adv / prep`）。
2. **词性集合兜底**：标注不可用或无原句时，回退到主技能报告该词的**词表词性集合**（如 `show` = `v & n`）；仍无则不做过滤（取全部义项）。
3. **按词性过滤词典义项**：
   - **有道本义**：只保留释义开头词性标注（`n. / v. / 【名】` 等）命中词性的义项。
   - **剑桥英英简义**：只保留 `pos-body` 块/词性头命中词性的义项。

**效果示例**：*show* 在原文 "a popular TV show about cars" 中作**名词**，则本义与英英简义只留名词义（如"演出、电视/广播节目"），剔除动词"展示/表明"等无关义。

> 说明：只按词性过滤删除的是**跨词性**义项；同一词性下的多个义项在第二级"原句搭配选义"里进一步精挑（无匹配则取前列，避免误删）。

## 学生记忆数据（技术文档 §7）

| 数据项 | 来源 | 覆盖 |
|---|---|---|
| 原句照搬 | 主技能报告原文例句 | ✔（超纲词也含原句）|
| 该词在原句中的词性 | 原句轻量 POS 标注判定；失败回退主技能报告词性列 | ✔ |
| 本义（词性过滤 + 首子义收敛）| 有道 `ec`（按释义开头 `n. / v. / 【名】` 等词性标注过滤，取每义项首个子义并剔专名）| ✔ |
| 词形变化（本课出现形式）| 主技能同一 lemma 的 forms | ✔ |
| 同源派生 | 有道 `rel_word.rels` | 部分词有 |
| 英英简义（词性过滤 + 原句搭配选义）| 剑桥 `dictionary.cambridge.org`（按 `pos-body` 块/词性头过滤，再按原句搭配词选义）| ✔ |
| 真实发音（音标+音频链接）| 有道 `simple`（uk/uk 音标 + dictvoice 播放链接）；缺失时用剑桥音标兜底 | ✔ |
| 双语例句 | 有道 `blng_sents_part` | ✔ |
| 难度锚点（层/CEFR）| 主技能归属层；CEFR 空时用剑桥词典徽标（B2/A1/A2 等）兜底 | ✔ |

## 用法

```bash
python scripts/student_cards.py --file 课文.txt --out 学生记忆卡
python scripts/student_cards.py --text "..." --out 卡
python scripts/student_cards.py --file 课文.txt --layer-filter KET,PET   # 只处理指定层
python scripts/student_cards.py --file 课文.txt --limit 10               # 调试:只前10词联网
python scripts/student_cards.py --file 课文.txt --offline                # 断网:只出主技能结果
```

> **推荐**：经主技能一键管道调用，自动先出分析再出本卡，无需记参数——
> `python scripts/vocab_pipeline.py 课文.txt`（默认含学生卡；`--steps 主,学生卡` 只出这步）。

> 提示：每词联网要发 有道+剑桥 两个请求，全量（如 100+ 词）较慢且偶被在线词典限流拖慢；调试/预览多用 `--limit` 分批或 `--layer-filter` 定向。

输出 `学生记忆卡.xlsx` 工作表「学生记忆卡」：Word | 归属层 | CEFR | 原句照搬 | 原句词性 | **例句词形** | **例句本义** | **例句义·英英** | **其他词形** | **本义扩展·其他义项** | 音标 | 派生词 | 双语例句 | 发音音频；并输出「实词表」「虚词表」（听写·默写抽查：词 / 例句词性 / 英文含义 / 中文含义 / 原文例句 / 译文），以及「专名词」表（地名/机构/物名等专名单词，`专名 | 频次 | 中文义`，认识常见专有名词）。

**单形单义原则**：每张卡片**首条对齐例句**——列 `例句词形` 取该 lemma 在**原句中实际出现的具体词形**（如 go 的例句含 went → 判定为 went），列 `例句本义`/`例句义·英英` 取该词性下**首条义项**（词典序，与例句语境最贴近）。其余（`其他词形` = 本文其他屈折形、`本义扩展·其他义项` = 该词性下其余义项）作为**扩展**一并附上，供掌握整词时用。例句中只有一个词形一个意思这一处，是第一优先呈现的对象。

## 边界（重要）

1. **两级消歧，逐级回退**：先按原句词性过滤（详见"按原句词性过滤"节）；再在同一词性内用**原句搭配实义词**（去停用词/短词/词本身）与剑桥各义项例句做交集计分，命中最高者胜出。原句与词典例句**无任何搭配重合**时不强选，保留该词性下前几条义项，避免误删。词典/标注缺失时逐级回退词表词性/全量，不误删。
2. **本义收敛**：有道常把某词性众多子义合并进一条释义（如 *show* 名词一条含"演出/节目/展览/见红/人名"），故取**首个"；"子义**收敛成短义项列表，并剔除人/地名专名义项；偶有语境义排在首子义之后（如 *run* 原句"run the engine"，其"奔跑/运转"义序在前），教学用可再润色。
3. **英英简义来自剑桥**：有道 `simple` 只返音标、牛津块加密不可用；英英定义来自剑桥，并顺带取 B2/A1/A2 等**词典 CEFR 徽标**作难度锚点兜底。剑桥释义条常含内链词（如 `to (cause to) compete in a race:`），已按 def-div 收尾 `</div>` 精确截取并保留核心措辞。
4. **超纲词含原句照搬**：主技能「超纲词」工作表现带**原文例句**，故 out 词"原句照搬"非空；其词性用有道释义开头词性缩写补足（如 `n. 快艇` → n），归实词/虚词表。
5. **在线依赖**：网络不可用或 nltk 未装时，自动跳过联网字段与 POS 消歧（回退词表词性/取全量），仅保留主技能结果；勿视为卡死。首次运行会自动下载 POS 模型（一次性）。
6. **搭配 1–2 例**：本版本暂以双语例句体现；显式典型搭配留待人工或后续语料。
7. **音标缺失**：个别屈折/病构词（如比较级 `healthier`）词典无音标，属正常。
