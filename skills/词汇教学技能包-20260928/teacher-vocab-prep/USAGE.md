# 使用文档：教师备课本（teacher-vocab-prep）

面向**教师备课**的软分支。复用主技能 `article-vocab-analyzer` 的静态分析结果，加工成**可直接进教案/命题**的 Excel 备课本。纯静态、零联网、无强依赖，跑得快。

---

## 1. 一句话定位

把课文的分层词卡、考点命题、超纲补卡、单元统计一次打包成 Excel（四页签），教师拿到就能挑重点词、出挖空/选词题、划教学梯度。

---

## 2. 何时触发本技能（自动调用前判别）

| 触发信号（用户一句话） | 我自动判断并执行 |
|---|---|
| "给我备课 / 备课词卡" | 出教师备课本（四页签） |
| "这单元的考点矩阵 / 命题角度" | 出「考点命题矩阵」页签（实词挖空+命题参考） |
| "重难点词卡 / 听写目标词" | 出「分层词卡」（按频次优先） |
| "超纲/进阶词补卡" | 出「超纲进阶补卡」 |
| 学生分支跑太慢，只要静态版式 | 走本分支（零联网） |

**我自己组装命令行**，例如：

```bash
python scripts/teacher_prep.py --file 课文.txt --out 教师备课本
python scripts/teacher_prep.py --text "..." --out 备课
python scripts/teacher_prep.py --file 课文.txt --band "全员(基础)"    # 只挑某教学梯度(逗号分隔)
python scripts/teacher_prep.py --file 课文.txt --out 备课_A           # 按课次分开出件
```

> 你只要说"备课""出考点矩阵"即可，参数我来填。易忘参数——说意图即可。

---

## 3. 输出四页签（Excel）

| 页签 | 内容 | 备课动作 |
|---|---|---|
| 分层词卡 | 教学梯度/归属层/词/词性/频次/跨句Range/CEFR/原文照搬 | 分层讲读、听写目标筛选（频次优先） |
| 考点命题矩阵 | 逐实词(n/v/adj/adv)：原文照搬 + 可挖空填空句 + 命题参考 + 考情提示 | 直接取材出挖空/听写/选词题 |
| 超纲进阶补卡 | out/NAWL/NGSL 按频次降序 | 进阶讲读、跨篇补卡 |
| 单元考点统计 | 各层词条数与占比 + 高频词 TOP15 | 单元难度概览、重难点分布 |

---

## 4. 与主技能 / 学生分支的关系

| 需要 | 用哪个 | 说明 |
|---|---|---|
| 通用分析/覆盖率/难度剖面 | 主技能 article-vocab-analyzer | 底层引擎，teacher/prep 都复用它 |
| 教师备课（本分支） | teacher-vocab-prep | 静态、零联网，出命题/词卡 |
| 学生记忆词卡（含释义/音标/音频） | student-vocab-cards | 需要联网补词典，逐词较慢 |
| 建班词库/累积三视图 | 主技能 `--db` | 跨单元累积，见主技能 USAGE |

**分工**：备考深度用 teacher（快）；生成学生自学材料用 student（联网补全）。

---

## 5. 边界（务必读）

1. **命题参考是自动化建议**：考点类型/挖空位/考情提示由词性/分层/CEFR 启发式生成，是备课**起点**，须结合教材与班情人工复核（"考情提示"的 CET 仅为难度定性，非真题命中）。
2. **版权红线**：KET/PET/中高考真题仅参考词表**自创同构仿真题**，不得照搬真题原文作命题稿。
3. **覆盖口径**：统计页为"词条口径"（去重 lemma）；完整 token 覆盖率看主技能报告。
4. **超纲词无词性/原句**：超纲词在词卡/矩阵中这两列为空属正常（仍可补卡）。
5. **不预置版式**：本分支只交付结构化备课数据，教案/界面版式由你二度加工。

---

## 6. 防健忘话术口诀

- 备课 → `出教师备课本`
- 考点/命题 → `出考点矩阵`
- 重难点/听写 → `分层词卡`
- 进阶补卡 → `超纲进阶补卡`
- 按梯度挑 → 说清"只要全员/中阶"即可

> **整合提示**：本脚本产出的 `<out>_*.xlsx` 会被主技能 `scripts/vocab_merge.py` 拾取，整合为 `<out>_教师版.xlsx`（权威合集）与 `<out>_学生版.xlsx`（学习向页签）；或由 `scripts/vocab_pipeline.py` 一键串联自动整合。
