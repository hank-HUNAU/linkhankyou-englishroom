# 聆听-跟读-听写 三环节数据清单（2026-10-16）

> 范围：跟读听写单文件（×28）+ 主站（index.html）+ 词汇诊断页；数据流权威源 assets/timeline.json。

## 1. 静态数据源（构建期内联，随页分发）

| 数据 | 结构 | 来源 | 消费环节 |
|---|---|---|---|
| `DB.TL[pg]` | `[[start_s,end_s],…]` 每句一段 | assets/timeline.json（ASR 对齐） | 听·整篇边界/逐句跳转；跟读·句区间+影子光标；听写·逐句播放 |
| `BOOK[pg]` | `{u, audio, title, arts:[[句…]], spk?, dialog?}` | index 原条目 + `_book_extra.json` | 听·正文渲染；跟读·正文/句级拆分；听写·句文本 |
| `DB.ZH[句]` | 句→中文译文 | 源文本管线 | 听·译文开关（cnToggle）；跟读·译文 |
| `DB.SPE[pg]` | 说话人数组（julia/mike…） | U12 对话篇 | 听·说话人标签 |
| `DB.LEVEL/TOPIC/BASE/TRAP` | 词级标注 | 逐篇补丁 | 正文词级着色 |
| `QUIZ`（`__QDATA__`） | `[{t:tf/choice/order, q, a, opts?, items?, src:"book TXX"}]` | `_quiz_bank.json`（12 篇 47 题） | 听·盲听答题卡 |
| `TYPES/UNIT_GROUPS` | 类型视觉 + 目录 6 组 | 模板内联 | 三环节·目录抽屉/芯片 |
| `FOLLOW_FILES[pg]` | 页码→单文件名 | `_gen_follow.py` 回写主站 | 主站·深链路由/可用性 |

## 2. 聆听（预习）节点

| 节点 | 消费 | 产出/写入 |
|---|---|---|
| 盲听开关 | `QUIZ.length>0 && !PROG.listen` | `#body.blind`（正文模糊）+ 横幅 |
| 整篇播放 | TL 整篇边界（wholeEnd）、`state.loopN/loopLeft` 循环、`state.rate` 变速、计时器 timerChip | 播完自动弹答题卡 |
| 答题卡 QZ | QUIZ 逐题（tf 三态 / choice 二选一 / order 点选排序） | `QZ.score`；反馈含正确答案 |
| 完成判定 | 得分 ≥⌈n×0.75⌉ | `PROG.listen=true` → `saveFollow()`（localStorage `tf_follow_<pg>`）+ 解锁正文 |
| 深链/权限 | `?pg=N&tasks=listen,…`（TASKS） | `prereqFor` 放行 |

## 3. 跟读（复习）节点

| 节点 | 消费 | 产出/写入 |
|---|---|---|
| 步骤1 跟句 | TL 句区间 + 循环 `state.loopLeft` | 句尾→间隙（fsGap"该你开口"） |
| 步骤2 影子 | TL + 词级光标（句内线性插值）+ `DB.SPE` 说话人 | FOL.track 影子轨迹 |
| 间隙/完成 | FOL.fstep、SHADOW_DELAY | 两步全过 → `PROG.follow=true` → `saveFollow()` |
| 译文 | DB.ZH（cnToggle） | — |

## 4. 听写（检测）节点

| 节点 | 消费 | 产出/写入 |
|---|---|---|
| 抽句 | pickpick：3 句/5 句（Top-K `sentScore`）/按段落（勾选）→ `DT.list` | 选句清单 |
| 三方式 waypick | key=键盘原位输入判分；paper=稿纸+核对答案；**nb=听写本**（逐句播放→原文→**逐词点击标错**，动词变化提醒→拍照微信群提示） | `DT.way` |
| 判分/自评 | TL 逐句播放（replayCurrentSentence/dtTimeupdate） | 键盘：逐词判分；nb：错词标记（页面内存） |
| 完成 | 全句完成 | `PROG.dictate=true` → `saveFollow()` |

## 5. 跨环节 localStorage 键总表（同源共享）

| 键 | 内容 | 写入方 |
|---|---|---|
| `tf_follow_<pg>` | `{listen,follow,dictate,updatedAt}` 三环节完成态 | 跟读页 saveFollow |
| `tf_current_student` | 当前学生姓名 | 主站/跟读页 |
| `tf_reports` | 学生×单元×类型×篇目 的 startedAt/doneAt 上报记录 | 主站 report()（跟读页通过同源可读） |
| `tf_assignments` | 教师下发任务（items[].engines、deadline） | 教师端写 / 学生端读 |
| `tf_guide_*` | 引导层状态 | 主站 |
| `theme_uN_records_v2` / `_tutorial_v2` | 主题词汇学习进度/教程 | 词汇诊断 theme 页 |
| 篇章词汇诊断页各自 `*_records_v2` | 篇章词汇进度 | 词汇诊断页 |

## 6. 上报数据结构（report → tf_reports）

```
tf_reports[学生名][unit][type(preview/review)][itemId(theme/pXXX)] = { startedAt, doneAt }
```
- 聆听完成 → 可由跟读页写 `done`（当前 PROG.listen 存 tf_follow，主站任务面板读 tf_follow 判定完成度）
- 教师工作台"去处理"→ 直跳引擎（engines 字段：vocab/follow；扩展 listen/dictate 已在跟读页支持）
